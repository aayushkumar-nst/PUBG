Gaming Hub  – Capstone Project


Overview
--------
- Goal: Build a PUBG-themed landing page using only basic HTML and CSS to demonstrate foundational layout, typography, and color skills.
- Features:
- Hero section highlighting the game’s vibe with imagery, bold headings, and call-to-action buttons.                -Sections for characters, game modes, and events styled with consistent color palette and hover states.
- Contact/footer area with simple social links using semantic HTML.
- Tech stack: Plain HTML5 for structure, CSS3 for styling (no frameworks, no JavaScript).
- Skills practiced: Semantic markup, Flexbox layout, responsive breakpoints with media queries, reusable utility classes, and accessibility basics (alt text, heading order).

How the CSS Is Organized:
- Layout classes rely on Flexbox for horizontal alignment and gap control.
- Shared utility classes handle padding, max-width, and text alignment to keep CSS DRY.
- Media queries at ~768px reduce font sizes, stack columns vertically, and resize imagery for smaller screens.
